# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-26

### Added

- RedFox Skills gallery plugin for DeepSeek Harness Web
- Sidebar entry to open a full-screen card gallery of `redfox-community-dsh` skills
- Category filter chips with labels from `lib/skill-categories.json`
- Real-time search by Chinese name / slug / description
- Skill README detail panel with Chinese / English switching
- One-click **Use now** to insert `/name` into the conversation input
- Auto-install of `redfox-community-dsh` when missing (restart still required)
- Selected card highlight and click-to-copy skill slug
- Manual **Refresh** button to reload the skill list
- Bilingual README (`README.md` / `README.zh.md`) with language switch links
